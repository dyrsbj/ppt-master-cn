# 中文企业 PPT 设计与验收规范

仅在官方 PPT Master 当前路线允许的内容策划阶段参考；不能覆盖其 BLOCKING 关卡或验收。

## 结构
- 管理层决策：结论 → 证据 → 备选方案 → 风险 → 待决策事项。
- 技术架构：约束 → 痛点 → 设计 → 关键机制 → 权衡 → 实施阶段。
- 项目复盘：目标 → 事实结果 → 偏差 → 成因 → 改进和负责人。
- 内部培训：目标 → 概念 → 例子 → 演练 → 小结。

## 单页
- 标题表达观点，而不只有“项目背景”“解决方案”。
- 每页只服务一项沟通目标；高信息密度不等于字体小或信息堆叠。
- 时间用时间线，步骤用流程，系统边界用架构，真实数量对比用图表。
- 统一设计系统，允许依据页面职能变化版式，不把整份 PPT 都做成重复的卡片。

## 简体中文
- 根据机器已安装字体选择微软雅黑、苹方、思源黑体或 Noto Sans CJK SC，不假定它们都存在。
- 保持数字、百分数、单位、标点、日期一致；图表声明数据口径和时间。
- 投屏可读，避免缺字、文本溢出、裁切、低对比以及颜色唯一编码。
- 不编造数据或引用；示意图明确标注“示意”。

## 验收
- [ ] 内容与来源一致，结论有证据。
- [ ] 页面无明显溢出、重叠、错位、乱码。
- [ ] 用户要求的元素已核实为可编辑对象，例外明确说明。
- [ ] 完成所选官方路线的全部必需检查。
- [ ] PPTX 文件存在且非空，提供真实路径与页数。
- [ ] 使用素材有许可，涉密资料没有未经授权外传。
